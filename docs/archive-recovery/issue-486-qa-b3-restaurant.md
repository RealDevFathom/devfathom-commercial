## `57b3e7f5` in detail

- **Comp reversal:** `src/app/api/restaurant/checkout/uncomp/route.ts` and its `route.test.ts`,
  with reversal logic in `src/lib/restaurant/bills.ts` (`src/lib/restaurant/reverse-comp.test.ts`).
- **Comp session attribution:** `terminalSessionId` is passed through `bills.ts` for comp and
  uncomp.
- **KDS unlock:** `src/app/api/restaurant/terminal/unlock/route.ts` verifies the operator
  credential first, then checks `kitchen:operate` on a KDS device. `develop` answers 403 with the
  capability name instead of the archive's 401, which is acceptable because the caller has
  already proved the credential. This change adds the missing route test: a wrong credential is
  refused before any capability lookup, a valid operator without kitchen access is refused with
  no session bound, and the credential check runs before the capability check.
- **POS touch targets and cash-total label:** `src/components/restaurant/pos/order-pad.tsx` uses
  `h-11` controls and labels the draft total "Estimated cash total".
- **Receipt discount line:** `src/components/restaurant/pos/receipt-view.tsx` renders
  `totals.discountTotal`.
- **"Primary" branch pill (dropped):** the archive overrode the pill in
  `src/components/restaurant/restaurant-branches-console.tsx` (~line 126) with
  `bg-primary text-primary-foreground`. `develop` keeps `<StatusPill status="Primary" tone="info" />`.
  `docs/design-system/DEVFATHOM-STUDIO.md` (Status) reserves pill colour for the shared
  `StatusPill` tones, and the primary fill is the call-to-action colour, so a status pill in
  that fill would read as a button. No product need justifies the override.
