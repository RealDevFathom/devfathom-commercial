# Restaurant technical architecture

Audit base: `ddc0bc9dde9642b63dd02dde869dd35f5564e8b9` (WHA-243).

## Runtime shape

- **IMPLEMENTED** — Restaurant is an organization vertical inside the Next.js application, not a separate service. Vertical/package activation creates a default branch and role templates; evidence: [`prisma/schema.prisma`](../../prisma/schema.prisma), [`src/lib/vertical-catalog.ts`](../../src/lib/vertical-catalog.ts), and [`tests/vertical-foundation.test.ts`](../../tests/vertical-foundation.test.ts).
- **IMPLEMENTED** — Authenticated back-office pages use tRPC routers mounted by [`src/server/routers/_app.ts`](../../src/server/routers/_app.ts); restaurant pages live under [`src/app/(app)/restaurant`](../../src/app/%28app%29/restaurant).
- **IMPLEMENTED** — POS and KDS are separate terminal pages backed by trust/session REST handlers; evidence: [`src/app/(terminal)/pos/page.tsx`](../../src/app/%28terminal%29/pos/page.tsx), [`src/app/(terminal)/kds/page.tsx`](../../src/app/%28terminal%29/kds/page.tsx), and [`src/app/api/restaurant`](../../src/app/api/restaurant).
- **IMPLEMENTED** — Restaurant persistence uses Prisma/PostgreSQL, organization-scoped records, forced RLS migrations, append-only ledgers where specified, and server transactions; evidence: [`prisma/schema.prisma`](../../prisma/schema.prisma), [`prisma/migrations`](../../prisma/migrations), and the [`tests`](../../tests) M2–M8 RLS/governance batteries.
