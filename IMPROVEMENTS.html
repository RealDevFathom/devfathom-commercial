Product Roadmap 2026

DevFathom Improvements

A product-strategy companion to the bug report. Bugs are "works but wrong"; this is "works but incomplete." DevFathom is already an unusually complete internal ops platform (projects + kanban, CRM, finance, HR, notes, realtime chat, video, LLM operator, public API). The biggest leverage now is closing half-built loops, lifecycle automation, and self-service trust features.

Top 5 Recommendations

5 picks
  1. 1
    Medium

    Close the Modeled-but-Unwired Loops

    Time tracking, task checklists/attachments, contact CRUD, and client status/logo are all fully modeled in the database — users just hit dead ends in the UI. High perceived-completeness ROI for days of work.

  2. 2
    Medium

    Financial Correctness as a Feature

    Per-currency reporting, server-derived invoice totals, and an invoice edit + PDF path turn finance from "looks right" into "trustworthy." Pairs with FIN-01/FIN-02 bug fixes.

  3. 3
    Big Bet

    HR People-Ops Depth

    Leave balances, team calendar, and off-boarding automation is the difference between "a leave table" and "an HR product." Without these, the HR module is decorative.

  4. 4
    Big Bet

    Account Trust & Recovery

    Self-service password reset, 2FA, and session management ("sign out everywhere"). A platform holding finance + HR data should not lack these. Password reset alone is Medium effort.

  5. 5
    Medium

    Relevance-Scoped Activity Feed

    The dashboard's most-viewed widget shows every company event to every user. Scoping it to the viewer's own projects, tasks, and mentions fixes DASH-01 and makes the dashboard genuinely useful.

Projects & Kanban

11 features

Missing / Incomplete Features

Big Bet Missing

Time Tracking

TimeEntry is fully modeled (Decimal(5,2), task/project links) but has zero routers or UI — the schema investment is completely stranded.

Value: Billing, utilization, and project profitability against client/project links already in finance.

Rationale: The schema investment is completely stranded, and finance already has the client/project links to bill against.

Medium Missing

Checklist Management

Only toggleChecklistItem exists — no create, rename, reorder, or delete for checklists or items. They appear only if imported from Trello, then render read-only.

Value: Core kanban capability — checklists are visible dead-ends today.

Medium Missing

Task Attachments

No render path and no add/delete UI (PROJ-04). Attachment data is modeled and counted but entirely unusable.

Value: Specs and designs live on cards; the feature is blocked until attachments work.

Quick Win Missing

Comment Edit / Delete

No updateComment or deleteComment — all comments are permanent. Table-stakes for any collaborative tool.

Value: Fix typos, remove mistakes, and moderate content.

Quick Win Missing

Board Rename, Label Edit/Delete, Project-File Delete

create/delete exist but no updateBoard, no label remove/recolor, and no file delete. Misnamed boards and accumulated labels/files are permanent.

Value: Avoid permanently-mislabeled boards and accumulating cruft.

Medium Missing

Subtasks, Dependencies, and Blockers

No parent-child or blocking relations between tasks. Delivery planning is limited to a flat board.

Value: Real delivery planning beyond a flat board.

Enhancements to Existing Features

Medium Enhancement

Board/Column Templates and WIP Limits

Default columns are hardcoded; every project starts with the same empty structure. WIP limits would help teams control flow.

Value: Faster project setup and flow control.

Rationale: Teams recreate the same structure each project — templates eliminate this friction.

Medium Enhancement

Bulk Task Actions

Multi-select move, label, assign, and delete across tasks. Currently every action is one task at a time.

Value: Manage large boards without exhausting click sequences.

Medium Enhancement

Pagination / Lazy-Load on Large Boards

getBoardWithTasks loads every task with all relations in a single query — large boards will become visibly slow.

Value: Sustained performance as boards grow in real use.

Quick Win Enhancement

Task Activity Timeline in Detail Sheet

Surface the task_created and task_completed activity events already being logged — they're invisible in the UI.

Value: Instant context on task history without leaving the card.

Quick Win Enhancement

Generalized "Done" Detection

Drive completion logging from the same column-name heuristic the UI uses for visual "done" state (relates to PROJ-07).

Value: Consistent done/not-done state between the board display and activity log.

Clients / CRM & Contracts

8 features

Missing / Incomplete Features

Medium Missing

Full Contact CRUD

Add/edit/delete contacts, set primary, and capture phone. The create form omits phone and allows only one primary — and updateContact doesn't exist yet (CLI-02).

Value: A usable CRM contact book that agents and admins can actually maintain.

Medium Missing

Client Activity Timeline

No per-client history of projects, invoices, contracts, or notes events. Account context is invisible before a client call.

Value: Account context at a glance before any call or proposal.

Quick Win Missing

Client Status Selector and Logo Upload

The status field (ACTIVE/INACTIVE/PROSPECT) has no selector in the edit UI, so PROSPECT→ACTIVE conversion is unreachable. Client.logo is modeled and shown but never settable.

Value: Basic CRM lifecycle management and visual polish.

Medium Missing

Contract Expiry / Renewal Reminders

endDate and an EXPIRED status exist, but nothing auto-flags or notifies when expiry approaches. The notify() email infra already exists and could drive this easily.

Value: Prevent lapsed agreements — high leverage against the existing notification infrastructure.

Rationale: The notify() email infra already exists, making this a wire-up rather than a build.

Medium Missing

Contract ↔ Project/Invoice Linkage and Value Rollup

Contracts attach to a client only — no tie to the governed project, no generate-invoice-from-contract, and no "total contracted value" view per client.

Value: Connects the full sales → delivery → billing chain in one place.

Enhancements to Existing Features

Quick Win Enhancement

Friendly Delete Guards and Inline Validation

Mutation errors are swallowed silently (CLI-01 + UX-01) — surface them as the Projects forms already do.

Value: Users understand why an action failed instead of wondering if it worked.

Quick Win Enhancement

Contract Status State-Machine and Date Validation

Any status → any status is currently allowed (e.g. TERMINATED→DRAFT). CON-01/CON-02 add dueDate/signedAt validation.

Value: Trustworthy contract lifecycle that can't be put into impossible states.

Quick Win Enhancement

Role-Aware Fetching and Richer Search

getById loads invoices/contracts then discards them for non-admins; list search matches name only. Extend search to contact name and industry.

Value: Faster lookups and less wasted DB work for non-admin roles.

Missing / Incomplete Features

There is no full invoice edit (only status changes) and no PDF/print or client-delivery path. Server-side total recompute (FIN-01) belongs here too.

Medium Missing

Partial Payments, AR Aging, and Overdue Automation

Model partial payments and auto-flip invoices to OVERDUE past dueDate (currently display-only). Include AR aging view.

Value: Accurate accounts-receivable — the current state understates overdue balances.

Enhancements to Existing Features

Quick Win Enhancement

Decimal-Safe Math and Bounded Date Windows

Harden FIN-04 (floating-point), FIN-08, and FIN-09 by computing in integer cents internally and bounding all date windows to the current date.

Value: Correct totals and no future transactions leaking into reports.

Quick Win Enhancement

Finance CSV Export and Date-Range Filters

Standard capability for any finance view — export filtered transactions and add proper date-range controls.

Value: Accountants can take data out without needing DB access.

Team / HR

7 features

Missing / Incomplete Features

Big Bet Missing

Leave Balances, Team Calendar, and Overlap Detection

No accrual/balance model, no calendar view, and no overlap guard (HR-02). Without these, the leave table is a fraction of what an HR module needs.

Value: Real people-ops — employees see remaining days; managers prevent over-booking.

Rationale: The current leave table records requests but can't answer "how many days do I have left?" or "is the team over-extended?"

Medium Missing

Off-Boarding Automation

Resignation approval records lastWorkingDay but never deactivates the account or revokes sessions — a security and process gap.

Value: Security and process hygiene — pairs with AUTH-01 token-version mechanism for force-logout.

Rationale: Pairs with AUTH-01's token-version mechanism for force-logout.

Quick Win Missing

Self-Service Leave Edit and Cancel

Employees can create pending leave requests but cannot withdraw or edit them — only an HR/Admin can remove a bad request.

Value: Reduces HR admin burden for trivial corrections employees can self-serve.

Medium Missing

Performance Review Workflow

PerformanceNote is admin-write/admin-or-self-read only. HR can't participate, and there's no review cycle, ratings, or configurable subject visibility.

Value: Turns a notes table into an actual review process with HR involvement.

Enhancements to Existing Features

Quick Win Enhancement

Separation of Duties on Approvals

Implements HR-01 — block self-approval and enforce PENDING-only transition so managers can't approve their own leave.

Value: Trustworthy approval records that pass a basic governance audit.

Quick Win Enhancement

Directory Privacy Controls

team.getAll returns email, phone, and bio to every authenticated user. Restrict contact fields to HR/Admin or make them opt-in.

Value: PII protection — employees control who can see their contact details.

Quick Win Enhancement

Include ON_LEAVE Staff in People Search

Team search filters status:'ACTIVE', invisibly dropping on-leave members from results and assignment dropdowns.

Value: On-leave team members remain discoverable and assignable during their leave period.

Settings / Profile / Auth

6 features

Missing / Incomplete Features

Big Bet → Medium Missing

Self-Service Password Reset

Only logged-in password change and admin reset exist. A locked-out user has no recovery path. The invite-token infrastructure can be reused for secure reset links.

Value: Table-stakes recovery flow that reduces admin load.

Rationale: The invite-token infra can be reused for reset links — most of the plumbing already exists.

Big Bet Missing

Two-Factor Authentication (2FA / MFA)

No second factor on a system holding admin, finance, and HR data. A single compromised password is the only barrier.

Value: Materially raises account security for the most sensitive platform in the company.

Medium Missing

Session Management — Sign Out Everywhere

Implements AUTH-01 — let users see active sessions and revoke them, including auto-revocation when password changes.

Value: User control after a suspected compromise; compliance requirement for finance + HR systems.

Medium Missing

Per-User Notification Preferences

notify() always sends email — no per-user channel or type opt-out. High-volume events create noise with no escape hatch.

Value: Reduces noise and respects user communication preferences.

Enhancements to Existing Features

Quick Win Enhancement

Live Password-Policy Checklist on Change Form

password-policy.ts exposes passwordRules but the settings form only checks length < 8 client-side. Reuse the shared checklist — the invite flow already does this.

Value: Client and server agree on the same rules; users see feedback as they type.

Quick Win Enhancement

Edge Token Verification and Consistent Page-Auth Guard

Implements AUTH-02/SEC-03 — verify the JWT in middleware and add a shared server-side auth guard so non-finance pages redirect cleanly too.

Value: Consistent auth experience across all routes, not just the finance module.

AI Assistant

4 features

Missing / Incomplete Features

Medium Missing

Authorization and Isolation Tests in the Eval

The eval proves tool routing but not the in-execute guards or cross-user data isolation (AI-02). A regression here would silently expose another user's data.

Value: Security model protected against regressions as the tool library grows.

Medium Missing

Streaming Citations and Action Audit Surfacing

Show which records the assistant used to answer a query, and link assistant writes into the audit/activity log.

Value: Trust and traceability for an operator bot — users can verify what the AI read and wrote.

Enhancements to Existing Features

Quick Win Enhancement

Groq Schema Discipline Lint

Fix AI-01 (pattern/allOf in resetMemberPassword tool schema) and add a guard that no tool schema emits format/pattern/allOf keywords — Groq rejects these with a whole-request 400.

Value: Prevents silent tool failures that break the entire assistant request.

Rationale: Groq rejects format/pattern/allOf at the schema level — one bad tool crashes all 96.

Quick Win Enhancement

Assistant Parity with App

Scope pendingLeaves and getTeamMember consistently with the underlying tRPC routers (AI-03/DASH-02) so the assistant and UI return the same data.

Value: Users get consistent answers from the assistant and the UI — trust depends on agreement.
